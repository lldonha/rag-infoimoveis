╔═══════════════════════════════════════════════════════════════════╗
║                      TROUBLESHOOTING                              ║
╚═══════════════════════════════════════════════════════════════════╝

❌ Erro: "Invalid API key"
   → Verificar se copiou a key completa (sem espaços)
   → Regenerar key no dashboard

❌ Erro: "Rate limit exceeded"
   → Aguardar 1 minuto e tentar novamente
   → Verificar se não está usando a mesma key em outro lugar

❌ Erro: "Quota exceeded"
   → Free tier atingiu limite mensal
   → Aguardar reset do mês ou upgradar para paid

❌ Erro: "API key não configurada"
   → Verificar se salvou o arquivo .env
   → Verificar se a variável está escrita corretamente
