┌─────────────────────────────────────────────────────────────────────┐
│              PROTEÇÕES ANTI-BLOQUEIO (7 CAMADAS)                    │
└─────────────────────────────────────────────────────────────────────┘

1️⃣  Rate Limiting
    ├─ Delays: 5-12 segundos
    ├─ Limite hora: 50 requests
    └─ Limite dia: 400 requests

2️⃣  Janelas Seguras
    ├─ Madrugada: 03:00 - 06:00
    ├─ Almoço: 13:00 - 15:00
    └─ Noite: 22:00 - 00:00

3️⃣  Browser Real
    └─ headless=False (Cloudflare não detecta)

4️⃣  Cookies Persistentes
    ├─ TTL: 6 horas
    └─ Renovação automática

5️⃣  Fingerprint Rotation
    ├─ User-Agent aleatório
    ├─ Viewport aleatório
    └─ Timezone do Brasil

6️⃣  Comportamento Humano
    ├─ Scroll gradual
    ├─ Movimento mouse
    └─ Pausas aleatórias

7️⃣  Auto-Recovery
    ├─ Detecção bloqueio
    ├─ Pausa 1 hora
    └─ Renovação cookies

    --mode full --max-properties 50      # Produção (50 imóveis)

  python tools/metrics_dashboard.py      # Dashboard terminal
  python tools/metrics_dashboard.py \
    --export                             # Exportar JSON

🗄️ BANCO DE DADOS
  psql -h localhost -p 5433 \
    -U postgres -d infoimoveis           # Conectar PostgreSQL

  SELECT COUNT(*) FROM properties;       # Total imóveis

  SELECT neighborhood, COUNT(*)
  FROM properties
  GROUP BY neighborhood
  ORDER BY COUNT(*) DESC
  LIMIT 10;                              # Top 10 bairros

🍪 COOKIES
  python tools/cookie_manager.py         # Info cookies
  rm .tmp/cookies.json                   # Forçar renovação
