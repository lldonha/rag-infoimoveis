### 1. BUG-001: Funções Assíncronas Corrigidas ✅

**Problema:**
- Funções de comportamento humano usando `time.sleep()` travavam o event loop
- Scraper parava de responder durante execução

**Solução:**
```python
# ANTES (síncrono - travava)
def human_scroll(page, duration: float = None):
    time.sleep(step_duration)

# DEPOIS (assíncrono - flui)
async def human_scroll(page, duration: float = None):
    await asyncio.sleep(step_duration)
```

**Arquivos modificados:**
- ✅ `tools/human_behavior.py` - 6 funções convertidas
- ✅ `tools/scraper_production.py` - 5 awaits adicionados
- ✅ `tools/scrape_workflow.py` - 2 awaits adicionados

## 💡 Aprendizados Importantes

1. **Cloudflare é o maior desafio**
   - Mais difícil que parsing de dados
   - Requer estratégia multi-camadas

2. **Headless=False é mandatório**
   - Cloudflare detecta headless browsers
   - Trade-off: mais lento mas funciona

3. **Seletores específicos > genéricos**
   - `tr:has-text("Tipo")` funciona
   - `[class*="tipo"]` não funciona

4. **"Wc social" = Banheiros**
   - Terminologia específica do site
   - Importante para completude

5. **Async/Await é crítico**
   - `time.sleep()` trava tudo
   - `asyncio.sleep()` permite concorrência
